Cargar e inspeccionar un PDF

La carga y la inspección son locales. Sólo una pregunta posterior a la IA puede enviar a OpenRouter fragmentos recuperados del PDF. Las llamadas al modelo pueden tener costo; el umbral aproximado 0,55 fue calibrado para este laboratorio con BAAI/bge-m3 y no es universal.

Máximo 10 MiB. El navegador hace una comprobación temprana, pero el servidor conserva la autoridad. Se admite sólo texto: hasta 20 páginas; el parser aplica MAX_PAGE_CHARS=20000, es decir, 20.000 caracteres extraídos por página, además de 200.000 caracteres extraídos en total y 120 fragmentos; no se realiza OCR y se rechazan PDF cifrados.
