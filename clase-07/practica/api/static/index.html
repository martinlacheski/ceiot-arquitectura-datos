Cargar e inspeccionar un PDF

La carga y la inspección son locales. Sólo una pregunta posterior a la IA puede enviar a OpenRouter fragmentos recuperados del PDF. Las llamadas al modelo pueden tener costo; el umbral aproximado 0,55 fue calibrado para este laboratorio con BAAI/bge-m3 y no es universal.

Máximo {{MAX_PDF_MIB}} MiB (el PDF se lee completo en memoria); el navegador hace una comprobación temprana, pero el servidor conserva la autoridad. Sin límite de páginas ni de fragmentos: la cantidad de fragmentos crece con el documento. La indexación tarda alrededor de 1,2 segundos por fragmento; un datasheet de unas 50 páginas tarda cerca de 2 minutos. Se admite sólo texto extraíble, no se realiza OCR y se rechazan PDF cifrados.
